## Implemented

- Input sources and actions are fixed enums covering head pose, gaze enter/exit,
  trigger, back/home, long press, recenter, pause/resume and source loss/restoration.
- Events require a positive monotonic sequence, finite non-negative timestamp, known
  source/action and a finite non-zero head rotation only for head-pose events.
- `SpatialInputRouter` dispatches from a bounded snapshot to at most 16 registered sinks.
  It rejects invalid/replayed events, deduplicates sinks, safely disables/restores lost
  sources and isolates throwing or self-removing sinks.
- Simulator and Cardboard sources implement the same `ISpatialInputSource` contract and
  produce the same typed payload. A missing controller never synthesizes a button press;
  the existing gaze-dwell path remains the fallback.
