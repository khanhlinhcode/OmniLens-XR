## Implemented

- `SpatialFocusState` composes the S03 `GazeDwellStateMachine`; it does not introduce a
  second timer or a generic callback path.
- Target descriptors require a positive target ID and a bounded allowlisted action ID.
  Disabled/missing targets and lifecycle loss cancel focus without selecting.
- One uninterrupted dwell can select once. Continued gaze never repeats and gaze exit
  is required to re-arm.
