**Task:** T-S04-01

## Implemented

- Versioned spatial UI tokens bound panel count, radial distance, dimensions, gap,
  angular safe zone and viewer-facing error. Non-finite values and invalid sizes fail
  closed.
- A deterministic layout validator rejects unsupported versions/modes/kinds, missing or
  duplicate IDs, zero/multiple primary panels, overlap, invalid orientation and positions
  outside the safe zone. Layout definitions copy caller panel collections defensively.
- `HomeLauncher`, `ThreePanelWorkspace` and `SettingsAccessibility` have matching mono
  and stereo definitions with stable panel/action identity. Panel centers lie on a radial
  arc and each panel yaw faces the viewer origin.
- The Unity fixture builder materializes three source-controlled scenes and generates an
  iOS project containing all three. Persistent dark-panel/focus materials, Body-tier text
  scaling and a static primary outline make scene contrast deterministic. The UI token
  candidates and ASCII wireframes are documented in the design specification.
