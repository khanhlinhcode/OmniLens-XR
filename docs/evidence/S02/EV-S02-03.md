# EV-S02-03 — Head pose, recenter and frame-time protocol

**Sprint / task:** S02 / T-S02-03  
**Date:** 2026-10-30  
**Current result:** IN PROGRESS — instrumentation, physical launch and stable frame-time

## Implemented instrumentation

`S02RuntimeProbe` writes bounded JSONL events both to the Xcode console and
`Application.persistentDataPath/omnilens-s02-runtime.jsonl`:

- 21 quaternion/Euler checkpoints (20 motion fixtures plus post-recenter neutral);
- a released hold of at least one second without consuming Cardboard's own trigger
  state;
- rolling 300-frame windows with average, p95, minimum and maximum frame time;
- focus, background/resume, camera-authorization and Cardboard device-parameter state.

The probe does not record camera frames, microphone, location, account, device ID or
arbitrary model output. Logs are overwritten on each fresh launch and contain only
fixed event names, elapsed time and bounded numeric/state fields.

## Manual fixture to execute

Start from a comfortable neutral pose and tap once at each target:

1. yaw −15°, −30°, −45°;
2. yaw +15°, +30°, +45°;
3. pitch −15°, −30°, +15°, +30°;
4. roll −15°, −30°, +15°, +30°;
5. yaw/pitch pairs (−30°, −20°), (+30°, −20°), (−30°, +20°), (+30°, +20°);
6. yaw/roll pairs (−20°, −15°), (+20°, +15°).

Return to neutral, hold the Cardboard trigger/touch for at least one second, release to
invoke the official sample's recenter, then tap once for checkpoint 21.

## Pass criteria

- All 20 motions produce finite, directionally consistent pose changes.
- A `recenter_hold_released` event exists and checkpoint 21 is near the new neutral
  reference.
- At least one 300-sample `frame_window` exists.
- The app remains responsive and no crash/error is present.

No 60-FPS, optics, readability or comfort claim is permitted from these diagnostics.
Until the physical fixture runs and its sanitized log is retained, the result remains
NOT RUN rather than inferred PASS.
