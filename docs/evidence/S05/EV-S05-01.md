## Implemented

- Typed, immutable `PanelDefinition`, `PanelBounds`, `PanelState`, `PanelCommand`,
  `PanelApplyResult`, `PanelSnapshot` and `PanelLifecycleEvent` contracts.
- IDs are restricted to 64 alphanumeric/dash/underscore characters. Kinds are an enum
  allowlist: Chat, Science3D, Document and Notes.
- Bounds reuse S04 size, minimum/maximum radial distance and angular safe-zone limits;
  NaN, infinity, behind-viewer and out-of-zone positions fail closed.
- `PanelRegistry` owns versioned state, caps panels at eight and rejects stale versions,
  invalid definitions, duplicate IDs, unknown IDs and invalid state transitions without
  incrementing the version.
- Snapshots copy and deterministically sort state by z-order then ordinal panel ID.
  Lifecycle metadata is capped at 64 events and contains sorted visible IDs only.
