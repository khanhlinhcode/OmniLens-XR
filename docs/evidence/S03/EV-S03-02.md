## Implemented

- `GazeDwellStateMachine` accepts dwell values only from 0.5–5.0 seconds and cooldown
  values from 0–5.0 seconds. Invalid/non-finite time fails closed.
- One uninterrupted focus can fire exactly one allowlisted action. Cooldown and a gaze
  exit are required before the same target can fire again.
- Target changes, missing targets, loss of focus, backgrounding and component disable
  cancel progress without selecting.
- `GazeDwellSelector` raycasts from the Cardboard reticle, accepts only layers 7/8 and
  components implementing `IGazeDwellTarget`, then re-verifies the same target before
  invocation. It never executes arbitrary model-generated code.
- A world-space progress ring is enabled only during focus/selection. Reduced-motion is
  the default. The existing trigger/tap path remains available as the faster path.
- The official sample's `ObjectController` implements the narrow allowlisted target
  interface and reuses its existing teleport action.
- A dedicated world-space `RECENTER` target on allowlisted layer 8 calls only
  `Google.XR.Cardboard.Api.Recenter`. Its callback rejects null and catches failures;
  the selector still requires cooldown plus gaze exit before it can run again.
