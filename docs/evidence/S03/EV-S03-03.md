## Implemented

- `S03ComfortProbe` creates a bounded local `omnilens-s03-comfort.jsonl` log, caps output
  at 2,000 rows, records a start checkpoint and the 5/10/20-minute crossings, and stops
  frame sampling after 21 minutes.
- Frame windows contain count, average, p50, p95, minimum and maximum frame milliseconds.
  Invalid frame samples are rejected rather than silently normalized.
- The iOS bridge records the public `NSProcessInfo.thermalState` category only. It does
  not claim an exact battery/SoC temperature; Celsius requires a separately identified
  external surface thermometer.
- Lifecycle events contain no raw image/audio, account, device ID, location or file path.
- `analyze_s03_comfort_log.py` bounds file size/row count, allowlists fields/events,
  rejects private identifier patterns, validates monotonic elapsed time, thermal values
  and percentile consistency, and refuses to report a complete run without checkpoints
  0/5/10/20, zero background/focus interruption and at least 18 minutes of measured
  frame coverage.
- `collect_s03_comfort_log.sh` copies only the app's comfort JSONL to standard output via
  the existing identifier sanitizer; the temporary directory is removed on exit.
