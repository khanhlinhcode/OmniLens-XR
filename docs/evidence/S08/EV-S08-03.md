## Implemented

- `Select`, `Isolate`, `Highlight`, `Focus` and `Clear` are explicit enum commands with
  expected scene version and allowlisted semantic part ID.
- Accepted commands increment the exact scene version. Unknown action/part, stale version
  and no-op reject without changing state.
- The view adapter verifies a complete part→view map, synchronizes state flags and keeps
  only the isolated branch, its descendants and ancestors visible.
- No command contains arbitrary method names, C# code, reflection, network or filesystem
  behavior.
