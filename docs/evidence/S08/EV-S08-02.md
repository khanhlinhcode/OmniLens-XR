# EV-S08-02 — Validated local asset loader

**Task:** T-S08-02  
**Date:** 2026-10-30  
**Result:** PASS

## Implemented

- A safe local source reads one filename below the S08 StreamingAssets root only after
  manifest provenance and budgets validate.
- SHA-256 is compared in fixed time before JSON mesh parsing. Asset ID, finite vertices,
  triangle indexes and manifest budgets validate before Unity `Mesh` construction.
- Missing, oversized, timeout, hash-mismatched, malformed or unprovenanced input returns
  a typed outcome and usable four-vertex tetrahedron placeholder.
- Loaded and fallback objects use idempotent `SceneAssetLease.Dispose`; owned mesh/material
  and root are released, while serialized shared material remains owned by the scene.
