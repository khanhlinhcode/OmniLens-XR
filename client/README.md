# Unity client foundation

`OmniLensXR` was generated by the official Unity CLI using Unity `6000.3.27f1` arm64 and template `com.unity.template.3d@9.1.0`, with Unity Cloud disabled. Unity Personal is active for the user-confirmed eligible personal use.

Google Cardboard `1.36.0` is pinned to tag `v1.36.0`; `packages-lock.json` resolves immutable commit `7fb2c0e438d2ef686f51cd59b53da16cc07b1b68`. Batch-mode import/compile passes. Unity now has 132 passing cases: 112 EditMode cases covering S01-S08 configuration/unit policy and 20 PlayMode cases exercising production physics raycasts, gaze state, panel lifecycle, persisted restore, validated mesh construction, scene selection and 50-cycle cleanup. Unity Analytics, Ads, Purchasing, Cloud Diagnostics, and Engine Diagnostics remain disabled in project settings.
